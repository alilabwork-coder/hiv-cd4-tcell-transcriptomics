# Analysis notebooks

This folder will contain reproducible Jupyter notebooks for the project.

## Planned notebooks

- `01_metadata_and_qc.ipynb`  
  Load the GEO series matrix, extract sample metadata, verify participant groups, select CD4+ T-cell samples, and perform initial quality-control checks.

- `02_exploratory_analysis.ipynb`  
  Explore expression distributions, identify possible outliers, and visualize sample structure using principal component analysis.

- `03_differential_expression.ipynb`  
  Compare progressive HIV samples with reference samples and report exploratory gene-level and pathway-level results.

## Analysis principle

All code should be reproducible from the public GEO data source. No confidential, unpublished, participant-identifiable, or restricted-access data will be added to this repository.
